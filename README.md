# Recursos de nube para Alya

Repositorio público de recursos instalables y multimedia para la aplicación Alya: fondos, vídeos, catálogo Alya Hub y paquetes publicados como releases. No contiene el código fuente de la aplicación Android ni credenciales.

Las utilidades de Alya Hub incluidas son recursos descargables; sus scripts y la web de calendario son públicos. La disponibilidad de material aquí no garantiza compatibilidad en todos los dispositivos.
